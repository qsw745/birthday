使用支持 · iPhone 与 Mac

把生日留在心上，
其余交给岁时。

这里整理了首次使用、本地通知、设备锁、iCloud 私有同步和数据导出的常见问题。 岁时不要求注册应用账号，所有核心功能都可以离线使用。

新版功能说明：iPhone 1.1、Mac 1.0 最低系统：iOS 17、macOS 14

版本与供应情况

本页介绍新版的 iCloud 与 Mac 功能，实际可下载版本请以 App Store 为准。早期 iPhone 版本仍可使用本机生日和提醒，不包含 iCloud 同步与数据导出。

快速开始

首次打开后选择是否允许通知，应用会直接进入月历。选择“＋”，填写姓名、农历生日和提醒时间即可。 生日先存入本机，不会等待网络。

Mac 上如何编辑和删除？

在“全部生日”中选择记录，双击或选择“编辑生日”即可修改。农历月份和日期使用下拉菜单选择；删除前会在窗口中央显示确认框，按 Esc 可取消。

没有网络还能用吗？

可以。查看、添加、编辑、删除、搜索、农历转公历和本地通知都由本机完成，不依赖开发者服务器。 离线期间的修改会保存在设备上，网络与 iCloud 可用后再尝试同步。

iCloud 同步如何工作？

同步默认开启，使用你的 iCloud 私有数据库在同一 Apple ID 的岁时设备之间合并生日。 你可以在“设置 → iCloud 同步”中关闭或重新开启；每台设备的开关互不影响，关闭不会删除本机生日。

同步时间取决于网络、系统调度和 iCloud 状态。远程通知只提示应用检查变化，生日提醒仍由每台设备本地安排。

更换或退出 iCloud 账号会怎样？

未登录时应用会继续保留并使用本机数据。检测到 iCloud 账号变化后，同步会暂停并要求确认； 只有确认使用新账号后，本机资料才会与新账号的私有数据合并。

如何导出生日资料？

打开“设置 → 数据导出”，选择“导出生日数据”，再用系统面板选择保存位置。 文件为 UTF-8 JSON，只包含当时本机可见的未删除生日；导出不会等待 iCloud，也不包含账号、同步令牌或通知权限状态。

为什么没有收到提醒？

  • 前往系统“设置 → 通知 → 岁时”，确认允许通知；
  • 在岁时“设置”页查看已安排数量和覆盖截止日期；
  • 确认生日当天或提前一天的开关至少开启一个；
  • 修改系统时区后，打开岁时并选择“重新安排本地提醒”。

本地生日提醒不依赖 iCloud 同步是否成功。

Face ID 或 Touch ID 会上传吗？

不会。生物识别和设备密码验证完全由系统处理，应用只接收验证是否成功的结果，不会读取、保存或上传生物识别信息。

需要注册账号吗？

不需要注册岁时账号。iCloud 同步由设备当前登录的 Apple ID 提供；即使未登录 iCloud，你仍可离线使用本机功能。

如何删除资料？

在生日列表中打开记录并选择“删除生日”。同步开启时，删除会在后续同步中传递到其他设备。 关闭同步或卸载一台设备上的应用不会自动删除 iCloud 中仍保留的数据。

仍然需要帮助？

请在邮件中写明设备型号、系统版本、岁时版本和遇到问题的步骤。不要发送密码、完整 Apple ID 或生日资料。 这些信息和你的发件邮箱仅用于答复与排查，保存和删除方式见隐私政策。
