# iOS 本地离线里程碑验收

## 自动化验证范围

模拟器自动化使用 `-ui-testing -network-disabled` 启动应用。该模式每次启动都会创建内存 SwiftData 存储和独立的测试偏好域，并注入不会展示 Face ID、不会请求通知权限或写入系统通知中心的测试服务。

- [x] 首次引导仍会出现，且可选择暂不开启通知
- [x] 经测试专用身份验证解锁后，可新增“妈妈”并在全部列表中看到
- [x] 可搜索“妈妈”、编辑为“妈妈更新”、保存并重新打开
- [x] 可确认删除“妈妈更新”，记录随后从本地列表消失
- [x] `-network-disabled` 已由组合根读取；当前离线里程碑不存在移动 API，因此测试路径不构造网络客户端

自动化结果只证明一次受隔离的模拟器会话内，本地新增、读取、搜索、编辑和删除流程不依赖服务器。内存存储不验证强制退出后的持久化；测试服务也不验证系统 Face ID、系统通知权限、锁屏通知、动态字体或 VoiceOver 的真机行为。

## 物理设备验收清单

状态：待在 iOS 17 或更高版本的实体 iPhone 上逐项执行。以下项目均未由本次模拟器自动化替代或判定为通过。

- [ ] 开启飞行模式后新增生日并立即出现在月历和全部列表
- [ ] 强制退出并重新打开后数据仍存在
- [ ] 编辑和删除均不等待网络
- [ ] 通知权限允许时，系统设置中可看到已安排请求
- [ ] 临时创建两分钟后的测试生日，锁屏状态收到本地通知
- [ ] Face ID 成功、失败和设备密码回退均符合界面状态
- [ ] 设置页显示安排数量和覆盖截止日期
- [ ] 动态字体最大级别下表单仍可滚动并完成保存
- [ ] VoiceOver 能读出公历、农历、姓名和同步状态
