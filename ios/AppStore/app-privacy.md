# App Store Connect 隐私问卷答案

## 跟踪

- 是否将数据用于跟踪：否
- 跟踪域名：无

## 收集的数据

以下类型仅在用户主动绑定服务器后传出设备；均与用户身份关联、不用于跟踪、用途仅为“App 功能”：

- 联系信息 → 姓名
- 联系信息 → 电子邮件地址
- 用户内容 → 电子邮件或短信
- 标识符 → 用户 ID
- 标识符 → 设备 ID
- 用户内容 → 其他用户内容
- 使用数据 → 产品交互
- 其他数据 → 其他数据类型

仅本地使用时，上述生日与提醒资料不会发送给开发者。Face ID 由 iOS 系统处理，应用不收集生物识别数据。

## Required Reason API

- UserDefaults：`CA92.1`，仅用于读取和写入应用自身的偏好设置。

问卷答案必须与 `BirthdayMobile/PrivacyInfo.xcprivacy` 保持一致。
