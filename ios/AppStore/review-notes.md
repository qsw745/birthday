# App Review 说明草稿

## 审核入口

本版本无需注册岁时账号或提供演示凭据：

1. 首次启动阅读本机优先与 iCloud 说明。
2. 通知页可以选择“暂不开启”。
3. 应用随后直接进入月历，使用右上角“＋”创建生日。
4. 在“全部”中搜索、编辑或删除生日。
5. 在“设置”中查看 iCloud 开关、同步状态、数据导出、生物识别和本地通知。

## 离线与同步边界

生日查看、添加、编辑、删除、农历转公历、数据导出和本地通知都先在设备上完成，不依赖开发者服务器。iCloud 私有同步默认开启，用于同一 Apple ID 的设备之间合并生日；用户可以在设置中按设备关闭。

没有网络、未登录 iCloud、iCloud 空间不足或同步暂时失败时，本机功能继续可用。同步到达时间取决于网络、系统调度和 iCloud 状态，不承诺即时到达。检测到 iCloud 账号变化时，同步会暂停，直到用户确认是否与新账号的私有数据合并。

CloudKit 远程通知只用于触发同步检查，不承载生日正文，也不会显示为生日提醒。App Store Release 的自有服务器地址为空，不会连接历史生日服务器。

## 权限说明

- 通知：按用户设置的日期和时间发送本地生日提醒。
- Face ID / Touch ID：保护本机生日资料；验证由系统处理，并支持设备密码回退。
- iCloud：只访问 `iCloud.top.qisw.birthday` 的用户私有数据库。
